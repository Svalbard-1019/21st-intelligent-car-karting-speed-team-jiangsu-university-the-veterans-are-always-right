# Portion3 与 Portion1 共用速度规划设计

## 目标

让 Portion3 的直线、转弯和终点减速行为与 Portion1 完全一致，消除路线中速度指令突然下降、恢复造成的“一停一走”体感，同时提高 Portion3 的转弯速度。

## 当前问题

Portion3 当前使用较低的独立弯道比例，并按固定点数估算前方转角。它没有使用 Portion1 的距离窗口、弯道档位滞回和连续加减速限制。因此，相邻路线点的角度变化会直接改变速度请求，造成指令突降和突升。

## 采用方案

Portion1 与 Portion3 直接共用同一个 `guandao_speed_planner_t` 状态和同一个速度更新时间状态。

- Portion3 使用 Portion1 的 2.4 米前方转弯检测窗口。
- Portion3 使用 Portion1 的弯道档位滞回。
- 两者使用相同的累计转弯比例：慢弯 `0.85`、中弯 `0.75`、急弯 `0.65`。
- 两者使用相同的单弯比例：普通弯 `0.80`、急弯 `0.65`、发卡弯 `0.60`。
- 两者使用相同的加速和减速斜率限制。
- 两者使用现有的相同终点减速曲线。

## 状态连续性

切换 Portion1 与 Portion3 时不重置共享速度规划器，也不把速度命令恢复到最低起步速度。共享状态保持连续。

共享速度规划器在系统上电时通过静态初值初始化为 `MIN_SPEED`，只初始化一次。进入或重新开始 Portion1、进入 Portion3 时都不重置规划器和速度更新时间。Portion3 首次启动零偏校准期间，车辆速度和转向输出继续保持为零；校准结束后，速度规划器从保存的共享状态继续运行。

## 保持独立的逻辑

以下 Portion3 专属行为不变：

- 800 点路线容量和闪存保存、读取。
- Portion3 路线索引、越点保护和最终停车距离。
- Portion3 首次启动 IMU 零偏校准和里程基线重置。
- Portion3 转向预瞄及路线几何。

## 代码范围

主要修改 `code/guandao.c`：

- 将 Portion3 纳入 Portion1 的距离转弯窗口、档位滞回和速度斜率限制条件。
- Portion3 选择 Portion1 的所有转弯速度比例。
- 把共享速度规划器静态初始化为 `MIN_SPEED`。
- 删除 `portion_1_reset()` 和 Portion1 启动阶段对共享速度规划器、速度更新时间的重置。
- 不在 `portion3_return_reset()` 中重置共享速度规划器和速度更新时间。

测试修改位于 `tests/`：

- 验证 Portion1 和 Portion3 使用同一速度规划器。
- 验证 Portion3 使用相同的距离窗口、档位滞回、转弯比例和加减速限制。
- 验证 Portion1 和 Portion3 的进入、重新开始流程都不重置共享速度状态。
- 验证 Portion3 首次启动校准和最终停车保护仍保留。

## 验收标准

1. Portion3 不再使用 KMS 专属的低速转弯比例。
2. Portion1 和 Portion3 的直线、弯道及终点减速计算路径一致。
3. Portion3 的速度命令通过同一个连续加减速限制器，不再随路线点角度突变。
4. 切换 Portion1 和 Portion3 不重置共享速度状态。
5. Portion3 首次启动校准、路线保存和最终停车测试继续通过。
6. 全部自动化测试通过。
