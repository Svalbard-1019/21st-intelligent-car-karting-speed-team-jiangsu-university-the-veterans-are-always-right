# Portion1 倒车精度、弯道速度与 PWM 渐降设计

## 目标

在不重新引入倒车左右摆动的前提下减小固定方向的倒车偏差，提高 portion1 前进弯道速度，并使普通行驶减速时 PWM 逐步退出而不是快速降到 0。

## 范围

- 只调整 portion1/KMY 行驶控制。
- portion3/KMS 参数保持不变。
- 直线加速度限制继续保持 3.5 m/s²。
- 真正停车、紧急停车和主动制动保持现有快速处理。

## 倒车前视

- 保持低速前视 0.35 m。
- 前视增长斜率由每增加 1.0 m/s 增长 0.60 m，改为增长 0.40 m。
- 菜单 `-10`（约 1.0 m/s）时，前视由 0.71 m 调整为 0.59 m。
- 最大前视仍限制为 1.20 m。
- 终点精调速度下仍回到 0.35 m。

## 前进弯道速度

KMY 比例调整为：

| 类型 | 原值 | 新值 |
|---|---:|---:|
| 普通弯 | 0.75 | 0.80 |
| 急弯 | 0.60 | 0.65 |
| 累计小弯 | 0.80 | 0.85 |
| 累计中弯 | 0.70 | 0.75 |
| 累计大弯 | 0.60 | 0.65 |
| 发卡弯 | 0.45 | 0.45 |

中高速普通弯统一使用路线对应的 `curve_speed_ratio`，避免固定 0.75 再次覆盖 KMY 的 0.80。KMS 保持自己的 0.70。

## 普通行驶 PWM 渐降

- KMY PWM 增大限制保持每个 100 ms 控制周期 600。
- KMY PWM 幅值减小时限制为每周期 300。
- KMS 继续保持当前每周期 1000，不改变 portion3。
- 当目标速度仍为正向时，普通速度 PID 不允许输出反向 PWM；目标为反向时同理，避免普通超速修正变成反向制动。
- 目标速度真正变为 0 时，仍调用立即停车。
- 主动制动继续使用独立的反向 PWM 状态机，不受普通行驶渐降限制影响。

## 诊断与版本

- 串口固件标记升级为 `cfg=p1spd7`。
- 增加 `pwmReq`，记录符号限制后的 PID 请求 PWM。
- 原 `pwm` 继续表示经过渐变限制后的实际中心 PWM。

## 验证

- 倒车前视曲线测试覆盖 0.4 m/s、1.0 m/s 和高速封顶。
- 源码测试覆盖 KMY/KMS 弯道比例隔离。
- 独立 C99 测试覆盖 PWM 增大、幅值减小、反向请求和过零行为。
- 测试真正零目标和主动制动路径仍保持原行为。
- 运行完整 Python 测试集、`git diff --check` 和 UTF-8 解码检查。
