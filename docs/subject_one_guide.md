# 科目一代码使用指南

这份文档给现场调试用，适用于当前 `kmy` 分支代码。

## 当前代码状态

- 后轮电机：科目一完整流程已经改为使用 `rear_motor` 模块，也就是测试里调过的载人 PID。
- 前轮转向：使用磁编码器闭环转向电机。
- 惯导：科目一仍使用原来的 `portion_1()` 路径追踪流程。
- 编码器：后轮 PID 和惯导共用 TIM2 编码器，`rear_motor` 只读累计差值，不清零，避免互相抢数据。
- 路线保存：不再需要 `SWITCH1`，打点时长按 `KEY1/S1` 约 1.5 秒保存。

## 按键说明

菜单中：

- `KEY3/S3`：光标向下，或参数 `+1`
- `KEY4/S4`：光标向上，或参数 `-1`
- `KEY2/S2`：确认，或参数 `+10`
- `KEY1/S1`：返回，或退出编辑

打点记录中：

- `KEY1/S1` 短按：原逻辑保留，可能用于记录倒车点
- `KEY1/S1` 长按约 1.5 秒：保存当前路线到 Flash

## 科目一速度怎么调

科目一要调的是 `Base_Speed`。

当前换算关系：

```c
实际目标速度 m/s = Base_Speed * 0.1
```

例子：

- `Base_Speed = 5`，约 `0.5 m/s`
- `Base_Speed = 8`，约 `0.8 m/s`
- `Base_Speed = 10`，约 `1.0 m/s`

第一次下地建议从 `Base_Speed = 5` 或 `6` 开始。

调速度步骤：

1. 上电进入菜单。
2. 进入 `Parameter`。
3. 进入 `Control`。
4. 选择 `Base_Speed`。
5. 按 `KEY2/S2` 进入编辑，屏幕会显示 `EDIT`。
6. 用 `KEY3/S3` 加 1，`KEY4/S4` 减 1，`KEY2/S2` 加 10。
7. 看屏幕上的 `Run_Mps`，它就是估算的实际 m/s。
8. 按 `KEY1/S1` 退出编辑，再按 `KEY1/S1` 返回上一级。

参数会在退出菜单后写入 Flash。

## 打点记录路线

打点前准备：

- 车放到科目一起点。
- 车身方向摆正。
- 确认 963RA yaw 正常变化。
- 推车时尽量慢速、匀速，转弯处更慢。

进入打点模式：

1. 上电进入菜单。
2. 进入 `Mode_Choice`。
3. 选择 `Guandao_Recode_Mode`。
4. 按 `KEY2/S2` 确认。
5. 进入 `Recode_Points` 后选择 `INS`。
6. 按 `KEY2/S2` 确认，蜂鸣器响一下。
7. 返回 `Menu_Main`。
8. 进入 `Car_Go`。
9. 屏幕显示 `Start` 后，再按 `KEY2/S2`。
10. 退出菜单后开始推车记录路线。

保存路线：

1. 推完整条路线后，把车停稳。
2. 长按 `KEY1/S1` 约 1.5 秒。
3. 蜂鸣器响一下表示保存成功。
4. 松开 `KEY1/S1`。

注意：推车速度不会作为自动跑的速度保存。自动跑速度由 `Base_Speed` 决定。推太快只会让路径点变稀、转弯不准。

## 跑科目一完整流程

跑之前确认：

- 已经保存过 `INS` 路线。
- `Base_Speed` 不要太大，第一次建议 5 或 6。
- 后轮方向正确。
- 前轮转向方向正确。
- 人站旁边，准备断电。

启动流程：

1. 上电进入菜单。
2. 进入 `Mode_Choice`。
3. 选择 `Guandao_portion_1`。
4. 按 `KEY2/S2` 确认，蜂鸣器响一下。
5. 返回 `Menu_Main`。
6. 进入 `Car_Go`。
7. 屏幕显示 `Start`。
8. 再按 `KEY2/S2`，车开始跑科目一。

## 当前科目一运行链路

代码运行关系：

- `Guandao_portion_1` 进入科目一完整流程。
- 主循环调用 `portion_1()`，计算路径追踪结果。
- `portion_1()` 输出：
  - `out_servo`：前轮目标角度
  - `out_v_l/out_v_r`：原本的左右后轮速度目标
- 当前代码取 `out_v_l/out_v_r` 平均值，换算成 m/s，交给 `rear_motor` 后轮闭环。
- 中断里不再对 `GUANDAO/DAOCHE` 调用旧 `Speed_Control()`。

关键换算在：

```c
#define GUANDAO_SPEED_TO_MPS    (0.1f)
```

如果 `Base_Speed` 已经调到合适范围，但实车整体还是太快或太慢，再改这个系数。

## 现场排查

如果车不动：

- 确认是否真的进入了 `Guandao_portion_1`。
- 确认是否按了 `Car_Go -> Start`。
- 确认 `Base_Speed` 不是 0。
- 确认后轮电机使能、PWM 接线、方向 GPIO 接线。

如果车反向跑：

- 先不要改路径。
- 检查后轮电机方向线。
- 也可能是 `daoche_speed` 或目标速度符号误用，先看当前是否在 `GUANDAO` 还是 `DAOCHE`。

如果路线偏很多：

- 先降低 `Base_Speed`。
- 检查打点时起点方向是否摆正。
- 检查转向方向是否反。
- 重新慢速打点，尤其转弯处要慢。

如果保存路线没有蜂鸣：

- 确认当前已经退出菜单，正在打点记录模式里。
- 长按 `KEY1/S1` 时间要超过约 1.5 秒。
- 按住直到蜂鸣器响，再松开。

如果速度太猛：

- 优先把 `Base_Speed` 改小。
- 建议测试值：5、6、8、10 逐步增加。
- 不建议第一次直接超过 10。

## 建议测试顺序

1. 架上确认后轮正转、反转、停车。
2. 架上确认前轮转向方向正确。
3. 下地低速打点并保存。
4. `Base_Speed = 5` 跑完整流程。
5. 路线稳定后逐步提高速度。
