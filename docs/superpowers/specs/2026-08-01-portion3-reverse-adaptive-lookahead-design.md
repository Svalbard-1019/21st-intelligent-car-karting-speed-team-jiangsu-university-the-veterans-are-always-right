# Portion3 倒车自适应预瞄与弯道降速设计

日期：2026-08-01

## 目标

解决 Portion3 保存后直接倒回时，路线后段在较高速度下实际预瞄距离缩短、转向命令过大并产生反复纠偏的问题。修改后应与 Portion1 倒车采用相同的随速度变化的米制预瞄，并在弯道到来前降低倒车速度。

## 根因

当前 Portion3 直接倒车按固定 5 个记录点选择目标。记录点间距并非严格恒定，且临近路线末端时目标索引会被限制到最后一个点，因此实际预瞄距离会逐渐缩短。纯追踪转向公式中的目标距离变小后，同样的航向误差会产生更大的转向命令。

同时，Portion3 直接倒车在绝大部分路线中始终使用菜单巡航速度，只在距离终点 0.5 米以内或进入最后两个点后才切换低速，没有根据前方弯度提前降速。高速、短预瞄和 1.40 转向增益叠加后，会出现方向打得过多、车辆偏离、再向反方向纠正的现象。

## 采用方案

采用“米制自适应预瞄＋弯道降速”。不采用仅降低转向增益或全程限速，因为这会掩盖目标点距离不稳定的问题，并损失低速弯道追踪能力。

## 自适应米制预瞄

复用现有 `guandao_reverse_lookahead_m(reverse_speed)`：

- 基础预瞄距离为 0.35 米；
- 倒车速度绝对值超过 0.4 m/s 后，速度越高预瞄越远；
- 最大预瞄距离限制为 1.20 米。

新增 Portion3 路线目标选择函数：从当前 `portion3_direct_reverse_route_index` 开始，沿已经反转的记录路线累计线段长度，选择累计距离首次达到预瞄距离的点；若剩余路线不足，则选择最后一个点。

该函数只读取路线点和当前索引，不修改 `portion_3.current_state`、`portion_3.current_point_index` 或 IMU 数据。原来的最近点搜索、0.20 米切点规则和终点越线保护继续负责推进路线索引。

## 弯道降速

根据“当前运动方向到自适应预瞄目标”的绝对航向误差，对菜单巡航倒车速度进行分级限制：

- 小于 15°：保持菜单巡航速度；
- 15° 至 30°：速度绝对值不超过巡航速度的 85%；
- 30° 至 45°：速度绝对值不超过巡航速度的 70%；
- 大于等于 45°：速度绝对值不超过巡航速度的 55%。

所有比例保持原倒车负号。现有终点 0.5 米低速规则优先级更高：进入终点低速区后，速度不得高于 `reverse_plan.fine_units` 的绝对值。

为避免速度在阈值附近跳动，转弯等级采用明确的滞回边界：0 级在达到 15° 时进入 1 级，1 级低于 10° 才退出；1 级达到 30° 时进入 2 级，2 级低于 25° 才退回；2 级达到 45° 时进入 3 级，3 级低于 40° 才退回。跨越多个阈值时允许一次进入对应更高等级。进入直接倒车时复位，倒车结束时清零。暂不修改 1.40 转向增益、32° 转向限幅和转向变化率，先消除实际预瞄距离与速度不匹配这一根因。

## CH5 一键保存并倒回

SBUS 解码增加 CH5：读取 `uart_receiver.channel[4]`，高于 1500 时将 `x6f_out[4]` 置为 200，否则置为 100；接收机无有效数据时必须恢复为 100，避免上电误触发。

CH5 使用“按下沿单次触发”，不要求长按。仅当系统处于 Portion3 路线记录模式、路线至少包含两个点、尚未保存且没有正在执行的保存任务时，按下一次 CH5 执行：

```text
CH5 按下
  -> 锁存 portion3_save_pending
  -> 调用现有 rear_motor_brake_start()
  -> 等待现有非阻塞刹车结束
  -> 记录停车后的真实端点
  -> 写入 Flash
  -> 调用现有 portion3_direct_reverse_prepare()
  -> 自动进入 DAOCHE 直接倒回
```

CH5 保持按下时不得重复触发；释放后才重新允许下一次触发。CH5 在其他路线记录模式、自动驾驶模式和普通遥控驾驶模式下不启动保存或倒车。实体按键长按与原 CH3 长按入口继续保留，三种入口最终都复用同一个 `portion3_save_pending` 流程。

串口记录诊断增加 `ch5` 和 `p3Trig`：前者显示解码后的 100/200 状态，后者显示本次 Portion3 CH5 单次触发是否已锁存，便于排查遥控通道映射和重复触发。

## 数据流与隔离边界

```text
菜单倒车速度
  -> guandao_reverse_lookahead_m()
  -> 沿 Portion3 反转路线累计米制距离
  -> 自适应目标点
  -> 航向误差
  -> 纯追踪转向命令
  -> 弯道等级限制倒车速度
```

不得修改以下内容：

- `update_state()` 的编码器和 IMU 惯导积分；
- `portion_3.current_state` 的写入方式；
- 最近点搜索和 `portion3_direct_reverse_route_index` 推进规则；
- 路线保存、RAM 反转及 Flash 内容；
- Portion1 正走、停车预滑行和倒车逻辑；
- Portion3 的终点截面、最终距离和停车判定；
- 自动规划禁用状态。

## 串口诊断

在现有 `P3AUTO` 行保留 `p3Rev`、`revIdx`、`revD100`、`revCmd10`、`act100`，并增加：

- `revLd100`：当前米制预瞄距离，单位厘米；
- `revTurn`：当前倒车弯道等级 0 至 3；
- `revSpd10`：弯道和终点规则处理后的倒车速度命令。

这些字段用于区分目标距离缩短、弯道降速是否生效，以及实际速度是否跟随命令。

## 异常处理

- 路线长度小于 3：沿用现有无效路线停车处理；
- 当前索引越界：目标选择函数内部限幅到有效范围；
- 剩余路线短于预瞄距离：使用最后一个点，不向数组外读取；
- 菜单速度异常：继续由现有 `guandao_reverse_speed_plan()` 限制在 -40 至 -2；
- 终点低速与弯道降速同时生效：选择绝对值更小的速度；
- 惯导或编码器异常：不新增自动规划或前进动作，保留现有停车保护。

## 测试与验收

### 自动测试

1. 以不均匀点间距路线验证目标点由累计米制距离选择，而不是固定点数。
2. 验证倒车速度提高时预瞄距离增大，且不超过 1.20 米。
3. 验证四个弯道等级分别输出 100%、85%、70%、55% 的负向速度。
4. 验证终点低速优先于弯道速度。
5. 验证目标选择和速度规划函数不写入惯导位姿与路线索引。
6. 验证 CH5 高电平只触发一次，保持按下不重复，释放后重新布防。
7. 验证 CH5 仅在 Portion3 记录模式触发，并复用现有停车后保存与直接倒回流程。
8. 验证接收机失效时 CH5 输出恢复为未按下状态。
9. 运行完整现有测试集，确保 Portion1 和 Portion3 停车规则保持不变。

### 实车验收

使用同一条 Portion3 记录路线，分别以倒车设置 -10、-15、-20 各运行三次：

- 高速时 `revLd100` 应大于低速时的数值；
- `revTurn` 增大时，`revSpd10` 的绝对值应按等级降低；
- 路线后段 `revCmd10` 不应因预瞄目标逼近而持续冲向 ±320；
- 不出现明显左右反复纠偏；
- 路线索引继续单调前进，不倒退、不跳出数组；
- 原终点停车位置与停车判定保持有效；
- IMU、惯导坐标和 Portion1 行为不发生变化；
- CH5 按下一次后先完成刹车和保存，再自动进入直接倒车；保持按下不重复保存。
